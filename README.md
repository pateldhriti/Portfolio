## 🎨 Design Highlights
The portfolio is designed with a modern, eye-catching **3D Light Theme** featuring:
- **Neumorphism / 3D Glassmorphism** card layouts that pop off the page.
- **Dynamic Particle Background** using an HTML5 Canvas particle engine.
- **Scroll-Reveal Animations** for a smooth, interactive browsing experience.
- **Typed Text Effects** in the hero section to highlight key capabilities.
- **Responsive Navigation** with a custom mobile hamburger menu.
- **Vibrant Gradient Accents** to draw attention to important elements.

## 🛠️ Built With
- **HTML5**: Semantic structure and layout.
- **Vanilla CSS3**: Custom CSS variables, flexbox/grid layouts, keyframe animations, 3D transforms (`translateZ`, `rotateX`, `rotateY`), and glassmorphic styling—all without relying on heavy frameworks.
- **Vanilla JavaScript**: DOM manipulation, `IntersectionObserver` for scroll animations, custom particle system, and typing effects.
